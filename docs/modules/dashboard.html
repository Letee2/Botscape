2. Estructura de Navegación

El dashboard está organizado funcionalmente para soportar distintos flujos de trabajo de inteligencia.

  • Overview: Métricas globales, volúmenes de actividad, idiomas y tendencias temporales (Heatmaps).
  • Investigación:
    • Graph Analysis: Visualización de relaciones (Nodos y Aristas) entre Bots, Malware y Operadores.
    • Operator Profiler: Información sobre los actores, sus Bots asociados, infraestructura, rutas de tráfico, etc.
    • Network Intel: Inteligencia recabada sobre URLs maliciosas donde operan Bots (phishing), así como dominios que reciben la información exfiltrada.
    • Bots: Panel específico para un Bot con toda la información asociada (origen, operadores del bot, relaciones, actividad).
    • Cluster Explorer: Permite explorar el cluster completo en el que se encuentra un bot, con detección de comunidades (Louvain), LLM para hipótesis sobre asociaciones y métricas de los elementos del cluster (centralidad, puentes).
  • Operaciones: Herramientas de gestión de ingesta, salud del sistema y monitorización de alertas (Breach Monitor).

3. Ingeniería de Frontend

Para superar las limitaciones de una aplicación web estática, implementamos varias optimizaciones críticas.

Gestión de Estado y Navegación

Utilizamos st.session_state para persistir el contexto entre páginas. Esto permite, por ejemplo, hacer clic en un bot en el Live Feed del Home y aterrizar en la página de Profiler con ese bot ya seleccionado. 

# Ejemplo de navegación contextual en ui/home.py
if st.button(f"Inspect {token}"):
    st.session_state['selected_token'] = token
    st.switch_page("pages/12_Profiler.py")

Caché Inteligente (TTL)

La capa shared/db/caching.py envuelve las consultas SQL con el decorador @st.cache_data. Definimos tiempos de vida (TTL) diferenciados según la volatilidad del dato:

  • Grafos (10 min): Consultas pesadas de topología.
  • KPIs (5 min): Métricas agregadas.
  • Live Feed (30 seg): Datos casi en tiempo real.

Componentes Personalizados

Inyectamos CSS y HTML crudo para crear elementos visuales avanzados que Streamlit no soporta nativamente, como las Risk Badges (etiquetas de riesgo de colores) y las Action Cards del menú principal.
