Hunter Engine

El script hunter.py es el motor de recolección de BotScape. Su misión es hacer uso de las herramientas que proporciona VirusTotal para identificar, extraer y validar tokens de Telegram de muestras maliciosas.

2. Estrategia de Búsqueda Híbrida

El Hunter utiliza una estrategia polimórfica que prioriza la configuración extraída sobre el contenido crudo para ahorrar recursos.

  • Búsqueda por Configuración: Utiliza malware_config. Si VT ya extrajo la configuración del C2, la usamos directamente. Es el método más rápido y económico.
  • Búsqueda por Contenido: Busca la cadena api.telegram.org en binarios (PE, ELF, APK) y scripts (Python) para casos donde la configuración automática falló.

Queries Implementadas

El sistema rota entre queries de alta fidelidad y de amplio espectro:

queries = [
  # 1. Configuración estructurada (High Fidelity)
  'malware_config:"api.telegram.org" fs:{since_date}+',

  # 2. Búsqueda Raw (Wide Net)
  'type:peexe content:"api.telegram.org" fs:{since_date}+',
  '(type:python OR type:powershell) content:"api.telegram.org"...'
]

3. Pipeline de Ingeniería Inversa

Para los binarios ofuscados, el ObfuscationHandler aplica técnicas de fuerza bruta dirigida en memoria.

Smart Peek: Antes de descargar, revisamos tags y names en el JSON. Esto reduce el consumo de cuota de descarga significativamente.

Rutinas de Decodificación

  • Base64 Recursivo: Detecta cadenas B64 anidadas dentro del binario.
  • XOR Brute-force: Busca la cadena ancla "telegram". Itera claves del 1 al 255. Si encuentra el ancla, usa esa clave para descifrar el payload completo automáticamente.

4. Persistencia

Los hallazgos alimentan tres tablas críticas para el análisis topológico:

  • bots: Inventario activo de amenazas.
  • samples_intelligence: Metadatos técnicos del malware (Hash, Imphash, SSDeep).
  • hash_origin: La tabla de enlace que permite la trazabilidad: "¿Qué malware está distribuyendo este bot?".
